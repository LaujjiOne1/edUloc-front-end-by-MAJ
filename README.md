# edUloc

Web application ported from the edUloc mobile repository. Replicates the starter application's complete navigation, theme toggle system, and interactive documentation explorer.

## Features

- **Home Screen**:
  - Animated Expo emblem with pulse glow and spring entrance
  - Quick action hint rows with click-to-copy functionality
  - Version and badge display with dynamic theme adaptation
- **Explore Screen**:
  - Interactive documentation guide with expandable collapsible sections
  - File-based routing tutorial
  - Platform support and multi-density asset documentation
  - Light/Dark theme configuration guide
- **Responsive Navigation**:
  - Floating pill top navigation bar
  - Instant Home / Explore tab switching
  - Interactive theme switcher (Light / Dark mode)
  - Direct links to official documentation

## Development

```bash
# Start development server on port 3000
npm run dev

# Build for production
npm run build

# Preview production build
npm run preview
```
